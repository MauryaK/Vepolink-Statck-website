FAQ

Frequently asked questions.

What is an IoT Data Logger?

An IoT Data Logger is a device that collects data from sensors, analyzers, meters and field instruments, stores the information and transmits it to remote monitoring platforms through internet connectivity.

What is the IoT Data Logger used for?

The IoT Data Logger is designed for real-time data acquisition, instrument monitoring, data logging and remote data transmission. It can be used in environmental monitoring, industrial automation, CEMS, CAAQMS and other IoT-based monitoring applications.

What communication interfaces are supported by the IoT Data Logger?

The IoT Data Logger supports RS485, RS232 and Ethernet communication interfaces. It can also communicate through Wi-Fi and cellular networks depending on the configuration.

Does the IoT Data Logger support 4G connectivity?

Yes. The device supports cellular connectivity through 4G CAT4. Customized configurations such as 5G and other cellular modules can also be supported depending on the application.

Can the IoT Data Logger work with environmental monitoring systems?

Yes. The IoT Data Logger can be integrated with environmental monitoring instruments and systems for collecting, logging and transmitting monitoring data. It is suitable for applications such as CEMS, CAAQMS and other environmental monitoring systems.

How much data can the IoT Data Logger store?

The IoT Data Logger supports local data storage through a TF card with expansion up to 1 TB. An optional 15GB eMMC internal storage configuration is also available.
