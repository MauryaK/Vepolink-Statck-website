Applications

Where it works.

A heated sampling probe extracts flue gas through a heated sample line and filtration system before entering the analyzer. The heated sampling path prevents condensation while the UV/IR analyzer continuously measures gas concentrations with high precision.

06 · FAQ

Frequently asked questions.

What is an Extractive Flue Stack Gas Analyzer?

It is an online gas analyzer designed to continuously monitor industrial stack emissions using an extractive sampling system.

Which gases can be monitored?

SO2, NOx, CO, CO2, O2, NH3, HCl, HF, Cl2 and other gases depending on application.

Does it support remote calibration?

Yes, the analyzer supports automatic and remote Zero and Span calibration.

Can it integrate with SCADA?

Yes, through RS232, RS485 and analog outputs.
